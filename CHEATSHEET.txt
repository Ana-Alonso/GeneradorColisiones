EXTRACTOR DE COLISIONES RPG - CHEAT SHEET
==========================================

USO RAPIDO
----------
1) Carga perfil con 1/2/3
2) Ajusta sliders principales
3) Revisa tipos con A/T/V/O
4) Corrige manuales si hace falta
5) Exporta con s

EJECUCION
---------
python generar_colisiones.py

El script abre selector de imagen al iniciar.

PERFILES
--------
1 -> bosque
2 -> ciudad
3 -> costa
4 -> custom
G -> guardar estado actual en perfil custom

MODOS
-----
Trackbar "Modo":
0 -> bordes
1 -> hsv
2 -> hibrido

TIPO HSV ACTIVO (HIBRIDO)
-------------------------
a -> agua
t -> tejado
v -> vegetacion
u -> aplicar H2/S2/V2 al tipo activo

TIPO MANUAL
-----------
o -> solido
a/t/v -> tambien cambian tipo manual (agua/tejado/vegetacion)

VISIBILIDAD POR TIPO
--------------------
A -> toggle agua
T -> toggle tejado
V -> toggle vegetacion
O -> toggle solido

RECTANGULOS MANUALES
--------------------
Mouse izquierdo + arrastrar: crear
Mouse izquierdo sobre rectangulo: seleccionar/mover
Arrastrar esquina inferior derecha: redimensionar
Mouse derecho sobre rectangulo: borrar

n -> seleccionar siguiente
p -> seleccionar anterior
x -> borrar seleccionado
z -> deshacer ultimo
c -> limpiar todos

Trackbars manuales del seleccionado:
Manual X, Manual Y, Manual W, Manual H

MERGE MANUAL
------------
m -> fusionar manuales solapados (mismo tipo)

Toggles merge por tipo:
k -> solido
l -> agua
b -> tejado
r -> vegetacion

Presets merge:
5 -> solo solido
6 -> solo agua
7 -> todos

GUARDAR Y SALIR
---------------
s -> guardar (abre dialogos imagen + json)
Boton GUARDAR en la imagen -> igual que s
q o ESC -> salir

SLIDERS CLAVE
-------------
Blur (impar)
Canny Low / Canny High
Kernel (impar)
H/S/V min/max
H2/S2/V2 min/max
Min W, Min H
Max W %, Max H %
Base %
Margen X %

TIPS RAPIDOS
------------
No detecta: baja Canny Low, revisa toggles de visibilidad.
Mucho ruido: sube Canny Low o Kernel.
Fragmentacion: sube Kernel.
Tipo hsv incorrecto: selecciona a/t/v, ajusta H2/S2/V2, pulsa u.
